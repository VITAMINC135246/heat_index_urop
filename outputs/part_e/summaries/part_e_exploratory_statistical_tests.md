# Part E Exploratory Statistical Tests

> **Deprecated cell-level test summary.** Formal exploratory tests are in
> `part_e_pixel_statistical_tests.csv`; all p-values remain exploratory because
> spatial dependence and the five-image pilot scope remain.

**Provisional-result rule:** This is a provisional pilot delta-T analysis using temperature matrices that have completed structural extraction QA but have not yet completed full radiometric parameter validation.

These tests use LUHK-cell or cell-by-surface-cover observations, not individual thermal pixels. All inferential results are exploratory because only five pilot images are included.

- Results table: `outputs/part_e/tables/part_e_exploratory_statistical_tests.csv`
- Image fixed-effect or cluster-robust models are deferred when the five-image pilot size makes them unreliable.
